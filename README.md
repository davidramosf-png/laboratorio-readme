# Sistema de Gestión de Biblioteca 
![Estado](https://shields.io)

BookFlow es una plataforma web interactiva diseñada para la automatización, control de préstamos y organización del inventario físico y digital de bibliotecas institucionales. *(Nota: Puedes encontrar la estructura completa del archivo README con todas las secciones de instalación, uso, tablas de estado, arquitectura y contribuidores en los documentos de referencia).*
